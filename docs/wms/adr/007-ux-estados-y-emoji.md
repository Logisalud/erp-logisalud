# ADR-007 — UX: estados, vacíos, errores y emoji

- Estados siempre con **texto + ícono + color**; el propietario siempre con **letra**; las capas del mapa con leyenda numérica.
- Cada pantalla tiene vacío, cargando (esqueleto, sin spinner infinito), error (qué pasó y qué hacer) y éxito (mensaje corto).
- **Sin emoji**: la skill de diseño los prohíbe como íconos y experiencia.md pide no abusar; usamos íconos dibujados (Lucide).
  La celebración vive en palabras ("Todo en orden", "Listo. El producto quedó dado de alta.").
- Español peruano con tuteo. El cargo es "Jefe de Almacén".
- "Cargando" no estaba definido en experiencia.md: se usa esqueleto y nunca se muestra algo confirmado si el servidor no confirmó.
